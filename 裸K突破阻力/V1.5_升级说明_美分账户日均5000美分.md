# 裸K突破阻力 复刻版 V1.5：升级说明（美分账户日均 5000 美分）

## 一、两份回测报告对照（XAUUSDm，2026-08-17 ~ 08-28，10 个交易日，固定点差 0.26）

报告 A 是 V1.4 EA 加载了「V1.3_实盘风控.set」。V1.3 独有的参数 V1.4 都没有，加载时被静默丢弃，包括
`InpAutoScaleMoney`、`InpCloseBy`、`InpNetCap`、`InpClockMode`、`InpAlertFloat` 等。
所以报告 A 并不是 V1.3 的行为。A 和 B 实际只差两项参数：

| 项目 | A：V1.3 set 加载进 V1.4 | B：V1.4 实盘 set |
|---|---|---|
| 方向K线实体触发距离 `InpSignalDist` | 1.00 | 2.00 |
| 开仓最大点差 `InpMaxSpread` | 0（关） | 0.45 |
| 净利 | 527.23 | 562.36 |
| 盈利因子 | 1.50 | 1.68 |
| 最大回撤 | 228.37（1.14%） | 538.55（2.64%） |
| 净利 ÷ 最大回撤 | 2.31 | 1.04 |
| 篮子数 / 亏损篮 | 33 / 0 | 31 / 0 |
| 日均已实现 | 52.72 | 56.24 |
| 最差一天 | 31.98 | 38.78 |
| 单篮最大单数 | 76 | 46 |

- 回测用的是固定点差 0.26，小于 0.45，所以点差闸在回测里一次都没有触发。两份报告真正有效的差异只有实体阈值 1.00 和 2.00 这一项。
- A 的回撤更小，来自 08-26 这一个篮子：B 在这天有一篮持仓 9.3 小时、41 单。这只是单一事件；而且 10 天、两边都是 0 个亏损篮，样本统计上分不出高下。
- 实盘必须保留点差闸 0.45。Exness 黄金在换日和数据发布时点差常常超过 0.45，A 方案没有点差闸，会在这些时刻照样开单。

## 二、日均 5000 美分的换算

- 5000 美分 = 50 美元。B 方案在标准账户 0.01 手的回测日均是 56.24 美元，已经覆盖这个目标。
- 美分账户 0.01 手，1 美元价格波动 = 1 美分。要达到 5000 美分/天，需要的倍率是 k ≈ 5000 ÷ 56.24 ≈ 89，取每单 0.90 手（k = 90）。
- 按同一份回测折算，日均约 5,062 美分，最大回撤约 48,470 美分（约 485 美元）。
- 结论：要赚同样多的美元，美分账户承担的美元风险和标准账户完全一样。唯一的好处是手数可以调得更细。

## 三、为什么要升级代码（V1.5 [P6]）

V1.4 的金额参数都是账户货币的绝对值。在美分账户上只把手数改成 0.90、不改金额参数，结果是：
13 美分的止盈会在大约 0.15 美元的价格波动内就被触发，这已经是另一个没有经过验证的策略。

如果继续用 V1.4、只改设置，需要手工把 4 个金额参数都乘以 90：
`InpTargetMoney`（整体止盈金额）→ 1170；`InpTrailMinGive`（移动锁利最小回撤金额）→ 270；
`InpStopLossMoney`（整体浮亏止损金额）→ 225000；`InpRcBeMoney`（遥控保本）→ 0。漏改任何一个，策略就会变形。

V1.5 的改动：

- **[P6] 金额参数自动缩放**。倍率 k = 每单手数 × 每跳价值 ÷ 跳动单位，4 个金额参数同步 ×k，篮子在价格上的形态不变。0.01 手时 k = 1，行为与 V1.4 逐笔一致。
- **[P7] 每日目标锁**（默认关闭）。今日已平仓盈亏达到目标后，当日不再开新篮。注意：打开它会截掉盈利多的日子，日均会低于 5000，所以随附的 set 里是关闭的。
- **[P8] 资金体检**。建议最低净值 = 有效浮亏止损 + 满仓保证金。程序自动识别美分账户，并把美分折算成美元显示。随附的 set 打开了「净值不足停开新篮」。

## 四、美分账户 set（裸K突破阻力_V1.5_美分账户_日均5000美分.set）

以 V1.4 实盘 set 为基准，只改了下面几项：

| 选项 | 中文 | 值 |
|---|---|---|
| `InpLots` | 每单手数 | 0.90 |
| `InpMoneyAutoScale` | [P6]金额参数按敞口自动缩放 | 1（开） |
| `InpDailyTarget` | [P7]每日目标 | 0（关） |
| `InpCapitalGuard` | [P8]净值低于建议最低净值时停开新篮 | 1（开） |

生效后的实际金额（k = 90）：

- 止盈 1,170 美分
- 锁利最小回撤 270 美分
- 浮亏止损 225,000 美分（2,250 美元）

## 五、风险账（必须看）

- 一次浮亏止损 = 225,000 美分 = 45 天的目标利润。只有触发止损的频率低于每 45 个交易日一次，长期才不亏。
- 10 天回测里 0 个亏损篮，这个样本无法估计止损频率。要用 ≥ 3 个月的回测，加上 DLS 原版 3.5 个月的实盘对账单里浮亏最深的那几篮，来核对这个频率。
- 建议最低净值 ≈ 225,000 + 满仓保证金（200 单 × 0.90 手 × 每手保证金）。以金价 4,400、杠杆 1:1000 估算约 304,000 美分，约 3,040 美元。实际值以面板「[P8]建议最低净值」为准。

## 六、部署

- 把 V1.5 和三个模块 .mqh 放在同一个 `MQL4\Experts` 目录下编译。三个模块是：品种自适应模块_MT4_v1.0、工业级UI面板独立模块_MT4_V3.1、指令挂单遥控模块_MT4_v1.0。
- 本版本只做了静态审计：括号配平、标识符声明、默认值与 V1.4 等价。没有在 MetaEditor 里编译过，也没有做任何回测。回测由使用者自行完成。
