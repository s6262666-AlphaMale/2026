# 裸K突破阻力 复刻版 V1.7：强平线口径 + 诊断修正

基于 V1.6。开平仓判定一行未改：`ProcessSlot`、`TradeAllowedNow`、`FirstOrderGate`、`CheckTakeProfit`、`CheckExtraRisk`、`OnTick` 与 V1.6 逐字相同。

依据有两份：4 个场景的零开单静态追踪及其对抗复核，以及对 V1.6 改动的对抗审查。

## 一、零开单根因（已确认）

V1.5 加载美分 set 后的关键参数：

- `InpLots`（每单手数）= 0.90
- `InpCapitalGuard`（[P8]净值低于建议最低净值时停开新篮）= 1
- 金额倍率 k = 90，有效止损 `InpStopLossMoney`（整体浮亏止损金额）2500 × 90 = 225,000

只看止损这一项，225,000 就已经大于起始资金 20000，跟杠杆无关。结果是每个裸K首单都被 `FirstOrderGate` 拦下，而加仓需要链里已有订单，所以整段回测 0 单。V1.5 拦截时一行日志都不写。

## 二、各版本改了什么

| 版本 | 改动 |
|---|---|
| V1.6 | [D1] 开单诊断；[D2] 资金不足时启动就给出结论；[D3] 去掉回测资金限制：[P8] 只在实盘拦截 |
| V1.7 [R1] | 建议最低净值改按券商强平线计算：有效浮亏止损 + 满仓保证金 × 强平比例（金额模式则加上强平金额）。Exness 强平线是 0%，所以门槛 = 有效浮亏止损。V1.6 的旧公式偏保守 5~13 倍，1:200 杠杆下 30 万美分的实盘也会被拦成零开单 |
| V1.7 [R2] | 倍率合理性告警：实测倍率 k 与"手数 ÷ 0.01"相差超过 2 倍时，启动就提示（比如美分品种的每跳价值口径异常） |
| V1.7 [R3] | 诊断修正，见下 |
| V1.7 [R4] | [P8] 统一用"风险口径净值 = 净值 − 篮子浮动盈亏"与门槛比较，不再把浮亏重复扣一次。修正前持仓浮亏 8 万美分时会误拦新篮，有浮盈时又放行过头。金额模式的强平线按 MQL4 语义（比的是可用预付款）把满仓保证金也计入门槛。止损关闭且强平部分为 0 时，日志明确写出"守卫无效" |

[R3] 诊断修正的具体内容：

- **零开单主因**：没信号的那个方向每个 tick 都会记一次"无信号"，以前会把 P8、冷却这类真实原因盖过去。现在的规则是：次数最多的原因如果是"无信号"，而当天又出现过只在有信号时才会记录的门槛类原因（冷却、停开新篮、P7、P8、P1），就以门槛类原因作为主因。偶发的点差尖峰盖不过全天的"无信号"。
- **挂载即被拦**：实盘挂载时如果一开始就被拦（比如自动交易没开），现在也会计入。
- **保证金不足**：冷静期纳入"当日首次即时打印"。
- **日期标签**：每日汇总改用原版时钟的日期。
- **净值为 0**：终端重启、账户还没登录完成时净值读成 0，这时不下资金结论，避免误报。
- **建议**：算出来的手数上限低于券商最小手数时，改为提示"降到最小手数需要多少风险口径净值"（按最小手数算，不再按当前手数夸大 90 倍）。
- **面板时段状态**：只有确实被其他图表持有时才显示"其他图表接管"；本图还没取得时段锁时显示"未取得时段锁（开仓许可被拒）"。
- **报价未就绪**：启动时报价未就绪而用了估算倍率，收到报价重算后会打印新的倍率；如果倍率异常，同时打印告警。

## 四、回测验收（由使用者完成）

1. **复现 V1.4**：V1.7 + 等同V1.4实盘_全键 set，环境与报告 B 相同（Exness-Trial XAUUSDm M15，2026.08.16–08.28，起始资金 20000，点差 260）。应逐笔一致：355 单，净利 562.36。
2. **美分方案**：V1.7 + 美分 set，环境相同，起始资金改为 300000。报告数字直接按美分读。
   - 盈亏约为报告 B 的 90 倍，但不会逐笔一致。原因是 0.01 手的单笔盈亏按分舍入，贴着止盈线平仓的篮子在 0.90 手下可能晚一个 tick 才平，之后的平仓价、冷却时间和加仓都会跟着偏移。
   - 复核者给出的实证：最晚在 2026-08-19 08:44 出现偏离。
3. **起始资金仍填 20000 也能开单**（回测已去掉资金限制），但这相当于 200 美元的美分账户：
   - 1:2000 杠杆下，最深时净值约 9,520，保证金比例约 117%，不会爆仓。
   - 1:200 杠杆下，从 08-17 10:16 的第 10 单开始保证金不足（错误 134），走势与报告 B 不再一致。
4. **日志页要能看到**：每天一行【开单诊断】；卸载时打印当天截至卸载的汇总和本次运行合计；资金不足时，启动日志有一行 ⚠【P8】提示。

## 五、实盘资金（美分方案，Exness 强平线 0%）

- **[P8] 门槛**：建议最低净值 = 225,000 美分（2,250 美元），比较对象是"风险口径净值 = 净值 − 篮子浮动盈亏"。低于这个数就不开新篮，启动时会弹 ⛔ 提示。已有持仓的浮亏不会造成误拦。
- **一次止损的代价**：一次浮亏止损 = 225,000 美分 = 45 天的目标利润。
- **建议入金**：≥ 300,000 美分（3,000 美元），给止损之外留出保证金和波动的余量。
